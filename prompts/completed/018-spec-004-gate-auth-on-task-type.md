<summary>
- A `build-fix` task can now start and run on a cluster that carries no GitHub App credentials at all.
- A `healthcheck` task likewise starts with no GitHub App credentials.
- The `security-review` task still fails fast and loudly at startup when its credentials are missing — the failure message operators and alerts already match is unchanged.
- A task whose type is unset or unrecognised keeps the strict behaviour: it fails at startup rather than silently running without credentials.
- Credential resolution is decided by one named rule that spells out which task types act on a repository, so the rule can be read and grepped instead of inferred from a condition.
- The GitHub token is absent from the agent's environment when no token was resolved — never present-but-empty.
- The startup path is covered by tests that drive the real gate for each of the three task types plus the unset and unknown cases.
- The architecture doc and the README both record the rule, so it does not die with this change.
</summary>

<objective>
Gate GitHub App credential resolution at startup on whether the task type acts on a repository. Today `main.go` mints an installation token unconditionally, so a `build-fix` task — documented in-repo as code-only, and deployed with no `APP_ID` / `INSTALLATION_ID` / `PEM_KEY` by design — dies before its first step with `security-reviewer auth: GitHub App credentials not configured`. Only `security-review` acts on a repository; `healthcheck` and `build-fix` must start with an empty token, while an unset or unknown task type must keep taking the strict branch.
</objective>

1. **Add the frozen predicate `requiresRepositoryAccess` to `main.go`** as a package-level function (not a method — the sibling entry point `cmd/run-task/main.go` gets its own copy with the same name in prompt 2, and that copy has no `TaskType` field to read from).

   ```go
   // requiresRepositoryAccess reports whether taskType acts on a repository and
   // therefore needs a GitHub App installation token at startup. Only
   // security-review acts on a repository; healthcheck and build-fix run without
   // GitHub credentials. An unset or unknown task type takes the stricter
   // branch — it is treated as repo-acting so it fails loudly at startup instead
   // of silently running without auth.
   func requiresRepositoryAccess(taskType agentlib.TaskType) bool {
   	switch taskType {
   	case prpkg.TaskTypeSecurityReview:
   		return true
   	case agentlib.TaskTypeHealthcheck, prpkg.TaskTypeBuildFix:
   		return false
   	default:
   		return true
   	}
   }
   ```

   Both sets are fixed by the spec: repo-acting is exactly `{security-review}`; non-repo-acting is exactly `{healthcheck, build-fix}`. The `default: true` arm is load-bearing — an unset or unknown type must fail loudly rather than silently run unauthenticated. A `switch` whose default is `false` (e.g. "anything that is not `security-review` runs without auth") is **wrong** for the unknown case; a predicate written as `taskType != build-fix` is **wrong** for `healthcheck`. Do not make this set configurable and do not derive it at call time.

   `main.go` already imports `agentlib "github.com/bborbe/agent"` and `prpkg "github.com/bborbe/security-review-agent/pkg"` — no new imports.

2. **Add the gate `resolveAuthIfRequired` to `main.go`** directly beside `resolveAuth`, and leave `resolveAuth` itself untouched (unexported, same signature, same error text, same `useGitHubApp` computation).

   ```go
   // resolveAuthIfRequired resolves GitHub App credentials only when the
   // configured task type acts on a repository. A non-repo-acting type
   // (healthcheck, build-fix) returns an empty token and a nil error, so the
   // task starts without credentials; an unset or unknown type takes the
   // stricter branch and fails fast inside resolveAuth.
   func (a *application) resolveAuthIfRequired(ctx context.Context) (string, error) {
   	if !requiresRepositoryAccess(agentlib.TaskType(a.TaskType)) {
   		glog.V(2).Infof(
   			"task-type %q does not require repository access — skipping GitHub App auth",
   			a.TaskType,
   		)
   		return "", nil
   	}
   	return a.resolveAuth(ctx)
   }
   ```
